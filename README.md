# 莉拉OK! / Liraoke

[English](README.en.md)

莉拉OK! 是一款面向 Windows 的卡拉 OK 视频制作工具。它把歌曲、歌词和背景素材放进同一个工作区，让你完成歌词整理、逐字打轴、画面预览，并导出带逐字扫色字幕的 MP4。

当前版本：**0.5.2.1**。支持手动制作，也可选用 AI 助手和本地自动打轴插件。

## 你可以用它做什么

- 导入歌曲以及图片或视频背景；
- 导入 TXT、LRC、SRT 歌词，或从 LRCLIB 搜索；
- 编辑中、英、日歌词，并离线准备语言、分词和日语读音；
- 跟随歌曲按键，为字、单词或演唱音节录制时间；
- 调整字幕样式、画幅、片段、裁切范围、节拍辅助和音频可视化；
- 预览成片并导出 H.264/AAC MP4。

## 主要模块

| 模块 | 用途 |
| --- | --- |
| 工作区 | 管理 `.lrn` 项目、歌曲、歌词和背景素材，支持自动恢复与整体迁移 |
| 歌词 | 导入、搜索和编辑歌词，处理中文、英文、日文及语言插件 |
| 打轴 | 按字、单词或演唱音节录制时间，支持局部重录、慢放和节拍吸附 |
| 时间轴 | 编排单轨视频或图片、调整片段、混音并裁切成片范围 |
| 字幕与画面 | 设置逐字扫色字幕、注音、字体、画幅和五种音频可视化 |
| AI 助手 | 连接自选模型服务，通过对话查询项目、辅助修改歌词与读音；写入操作需确认 |
| 自动打轴 | 按需安装本地对齐插件，生成可复核的逐字时间，保留人工打轴点 |
| 音乐搜索 | 搜索歌曲并导入可用音源，服务可用性取决于对应平台 |
| 预览与导出 | 使用同一套渲染逻辑预览并输出 MP4 |

## 快速开始

1. 下载并完整解压 Windows x64 便携包；不要只复制 EXE。
2. 运行 `Liraoke.exe`，新建工作区并导入歌曲。
3. 添加歌词和背景素材，在“歌词打轴”中跟随演唱按空格录制。
4. 预览字幕和画面，设置输出规格后导出 MP4。

便携包已包含 .NET 运行时、FFmpeg 和日文词典，无需安装开发工具。AI 助手需自行配置服务地址和 API Key；自动打轴模型按需下载，CPU/GPU 要求见 [本地对齐插件说明](docs/LOCAL_ALIGNMENT_PLUGINS.md)。

项目文件使用 `.lrn` 格式并引用工作区内的相对素材路径，因此整个工作区可以一起移动。旧版 `project.kfp` 单轨项目仍可打开。

## 当前边界

- 仅支持 Windows x64；
- 当前编辑模型为单轨背景视频／图片；
- 自动语言识别和日语注音需要人工复核，尤其是专名和生僻字；
- 节拍分析和节拍器是可选辅助，不会替代歌曲时间轴；
- 不包含 AI 自动制片、复杂视频特效或外部字幕工程导出。

## 系统要求与已测试环境

最低支持系统为 **Windows 10 版本 1809（Build 17763）x64**；也支持更高版本的 64 位 Windows。便携包已包含运行所需的 .NET、FFmpeg 和日文词典。

当前开发机已完成自动测试和本地构建，配置如下：

| 项目 | 配置 |
| --- | --- |
| 操作系统 | Windows 11 专业版 64 位，版本 10.0.26200（Build 26200） |
| 处理器 | AMD Ryzen 7 9800X3D |
| 内存 | 32 GB（系统可用物理内存约 30.8 GiB） |
| 独立显卡 | NVIDIA GeForce RTX 5080，驱动 32.0.16.1088 |
| 集成显卡 | AMD Radeon Graphics，驱动 32.0.21030.2001 |

这只是已验证配置，不代表最低硬件要求。较旧或低配置设备上的长时间预览、整曲导出和性能仍需实机验证。

详细需求与架构见 [MVP 需求与技术架构](docs/MVP_REQUIREMENTS_AND_ARCHITECTURE.md)。语言插件作者可阅读 [语言插件开发说明](docs/LANGUAGE_PLUGINS.md)。
