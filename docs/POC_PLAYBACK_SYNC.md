# PoC 01：音频主时钟与键盘打点

## 目标

验证歌曲播放、UI 播放头和手动打轴时间均以 WASAPI 设备实际渲染位置为准，而不是 UI 定时器或提前读取的音频流位置。

## 当前实现

- 打开本地 MP3 或 WAV；
- WASAPI 共享模式，50 ms 请求延迟；
- 使用 WASAPI audio clock 的已渲染字节数计算项目时间；
- 播放、暂停和时间轴跳转；
- 空格记录当前时间；
- 退格撤销最近记录，音频不中断；
- Esc 暂停；
- UI 以约 24 fps 采样主时钟和刷新字幕，但 UI 定时器不参与走时。
- 视频按片段绝对时间选择素材，源入点与裁切时长参与定位；
- 视频画面与 WASAPI 主时钟相差超过 120 ms 时尝试跳转纠偏；
- 片段间隙隐藏画面，显示黑场；
- 时间点可应用为逐行或逐单元歌词数据；
- 选中行提前 3 秒进入与区间循环；
- 演唱单元编辑、合并 / 拆分与项目编辑撤销 / 重做。

## 运行

```powershell
dotnet run --project src/KaraokeFilmMaker.App
```

也可以在 Visual Studio 中将 `KaraokeFilmMaker.App` 设为启动项目后运行。

## 手工验收

待 MVP 功能齐备后统一执行以下步骤。

1. 创建工作区并导入一首至少 10 分钟的 MP3 或 WAV；
2. 播放、暂停、恢复，确认计时不会在暂停时继续；
3. 拖动滑块跳转到多个位置，确认声音和计时从目标附近恢复；
4. 播放时连续按空格，确认时间点严格递增；
5. 按退格，确认最后一个时间点被删除且播放不中断；
6. 播放 10 分钟，观察声音和计时显示是否有明显异常；
7. 记录音频设备、文件格式和任何错误信息。

## 当前边界

- 视频画面已接入 WPF MediaElement，但长时间音画漂移和片段切换尚未端到端验收；
- 视频预览播放器静音；主歌曲和未静音片段原声由 FFmpeg 合成 PCM 缓存，再通过同一 WASAPI 主时钟播放；
- 已实现 0.5×/0.75×/1× 保持音高变速缓存，并映射回歌曲原始时间；
- 已实现波形、低分辨率代理、缩略图及图形时间轴拖动；
- 暂停时冻结已渲染位置并重建输出，避免缓冲帧使暂停后的计时继续；真实音频设备自动测试覆盖播放、暂停、恢复和跳转；
- 已接入完整 MP4 合成；1080p 的 24/30/60 fps、音轨、黑场、视频裁切及取消保留原输出均已自动测试；
- 10 分钟持续播放、VBR MP3、多种音频设备和低配电脑仍需按以下标准统一人工验收。

## 通过标准

- 暂停、恢复和跳转不崩溃；
- 键盘记录时间来自音频设备时钟；
- 连续播放期间时间单调递增；
- 撤销不打断声音；
- 10 分钟播放没有可观察的累计计时异常。
